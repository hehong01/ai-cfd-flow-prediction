# AI-CFD Flow Prediction

Reconstruction and extension of an undergraduate AI-CFD project for facial external-flow and heat-transfer field prediction.

The repository is organized in the original workflow order:

1. Image to STL
2. SpaceClaim preprocessing
3. Fluent CFD
4. CFD dataset generation
5. MLP / DGCNN model training
6. AI prediction
7. 3D visualization

Implementation and documentation will be added step by step while distinguishing original project work from later reconstruction and extension.
